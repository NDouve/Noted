<<

<<
<< # Plan
<<
<< Ship the **AI box**.
<<

## Reviews
Every diff went to `reviewer`. The visible changes also went to `reviewer-ui`.

**Blocking findings, all resolved:**
- **T0 (core):**
  - The AI markers in the markdown snapshot could be forged; `<` is now escaped.
  - Also fixed: a nonce was added to the link, keys are hashed as UTF-8, and the block type is part of the fingerprint.
- **T2 (app):**
  - A write could race the opening of its page; `open()` now reads inside the save queue.
  - A second Noted could bring back a revoked token; the connections are re-read from the file on every check and write.
- **T1 (AI box):**
  - An AI write of `![](url)` became an image block, and opening the page then fetched a remote URL or a UNC path with no click. The markdown import now keeps an allowlist of text blocks.
  - A replace write whose content equalled the editor's last build was ignored, and the next keystroke committed over it. The editor now restarts on every outside change.
- **Curation:** the wire format of the link in 0106 was wrong; it now gives the exact greeting and request JSON.

**Non-blocking findings fixed:**
- Link and noted_mcp:
  - The flush timeout, line limits and invariant-scan gaps.
  - Script parameter validation, and the Box only box count.
- Settings and the link:
  - A missing or damaged settings file no longer verifies a token from memory.
  - `busy` instead of `bad_token` while the settings can't be read, with no stale flag carried to the next check.
  - A code from a newer app keeps its message.
- The AI mark also covers inline formulas and link targets.
- AI box:
  - Unsafe link schemes are dropped.
  - Insert no longer crashes on a page whose boxes lack bounds.
- Tests:
  - The end-to-end test's process cleanup on Windows, its shorter timeouts, and the extra rejection cases.
  - Tighter assertions in the integration suite.

**Found by the integration suite and fixed (b0af82f):** after an outside change, the restarted editor lost the focus without the page hearing of it. Escape and Ctrl+Z then did nothing until another box was clicked. The new editor now takes the focus, and a box that can't be edited isn't restarted.

## Decisions the PM made
- **Box API 0.9** (additive), recorded in the changelog and in 0107:
  - `AiWriteMode` and `AiWrite`;
  - `BoxCodec.aiOwner` and `BoxCodec.aiWrite`;
  - `CommandHost.viewCentre`;
  - `CanvasController.insertBox(autofocus)`.
- **New package** `packages/boxes/ai` (`noted_box_ai`). It adds no external dependency; the app depends on it by path.
- **No new dependencies.** `crypto` was already a noted_core dependency. The end-to-end test speaks JSON-RPC itself, so the app gains no `dart_mcp` dependency.
- **Loopback TCP with a nonce instead of a named pipe** (see Needs the maintainer):
  - Dart can't serve a Windows named pipe without FFI.
  - `dart:io` can't open `\\.\pipe\` paths.
  - Binding a Unix socket failed on Windows.
- **The AI-written mark** is a fingerprint, not a flag: editing a block ends its mark with no clean-up.
- **Revocation** leaves boxes untouched. An owner id that isn't a current connection owns nothing, so no page is rewritten.
- **`<ai-written>` markers** in the snapshot, with `<` escaped.
- **`mode` is required** in `write_box`, so an AI never replaces a box by accident.
- **`busy`** answers "still starting" and "settings unreadable for a moment". A missing settings file means no connections.
- **An AI box is never removed as empty.** Otherwise opening the Connected AI menu removed a new box.
- **The markdown import drops images, code blocks and raw HTML** (see Needs the maintainer).
- **`next.md` cited D-054 and D-031.** No entries have those numbers, so I read them as 0028 (the AI-authored tag) and 0020 (per-box conflicts).
- **The run's date** is 2026-11-01, New York time at the report. Decisions 0103–0107 are dated 2026-10-31, the day `next.md` approved them.

## Needs the maintainer
1. **The local connection: loopback TCP or a named pipe.** This run departs from the approved request: `next.md` asked for a named pipe on Windows, and the link is loopback TCP, because Dart can't serve a named pipe without native code. It is recorded in 0106 and works today, but it changes an approved item at the MCP boundary, so it needs your sign-off.
   - Options:
     - (a) keep loopback TCP with the nonce check (works on every desktop platform);
     - (b) a Windows named pipe, served by the app through FFI, with an FFI exception for the server's link client.
   - Recommendation: **(a)**. The nonce stops a client from sending a token to another program that took the port, and (b) adds native code on both sides.
2. **Box only reads are scoped by the token's id alone.** The server can't hash, so any key with a listed id reads that connection's boxes. The id is in `settings.json` and in each owned box. Writes always verify the full token in the app.
   - Options:
     - (a) keep this;
     - (b) allow SHA-256 (package `crypto`, already used by noted_core) in the server, which means relaxing the invariant test's ban on crypto libraries for hashing only;
     - (c) have the server ask the running app to verify the token. Reads would then need the app.
   - Recommendation: **(b)**. Hashing is neither key access nor decryption, and reads keep working without the app.
3. **Ctrl+Z while an AI box is open for editing** goes to the editor's own history, which an AI write empties. The page undo runs after Escape, or from the toolbar. Note boxes behave the same after an outside change.
   - Options:
     - (a) keep it;
     - (b) when the editor has nothing to undo, pass Ctrl+Z to the page undo.
   - Recommendation: **(b)**, for both box types.
4. **Fenced code blocks and raw HTML in an AI write are dropped.** The note box has no code block type.
   - Options:
     - (a) keep dropping them;
     - (b) keep their text as plain paragraphs;
     - (c) add a code block to the note box.
   - Recommendation: **(b)** now, **(c)** later.
5. **AI boxes on Off pages.** Insert → AI box works on any page, but on an Off page no AI can reach the box, and nothing says so.
   - Options:
     - (a) disable Insert on Off pages;
     - (b) show "AI access is Off on this page" in the box header.
   - Recommendation: **(b)**.
6. **Two Noted instances on one computer.** Each would start a link and write `ai-link.json`, and the last one wins. Connections stay consistent, because they are re-read from the file.
   - Options:
     - (a) a single-instance guard, so a second launch focuses the first;
     - (b) leave it.
   - Recommendation: **(a)**, as its own task.
7. **Per-box AI-read and AI-write switches** (0008) are not built; every AI box takes writes from its owner. Recommendation: decide whether they are still wanted with per-AI rules (out of scope now).
8. **Toolbars at narrow widths.** At about 1000 px, the Contextual insert group and the Tabs Home row are cut off, with no overflow control, which now hides AI box in Contextual.
   - Options:
     - (a) an overflow ("More") menu for whatever doesn't fit;
     - (b) let the groups scroll sideways.
   - Recommendation: **(a)**, as its own task. This changes the toolbar design, which is why it is listed here.
9. **reviewer-ui's instructions.** `.claude/agents/reviewer-ui.md` doesn't point to the committed script yet. Suggested line: "Script for this method: `app/scripts/screenshot-window.ps1` (run with `powershell -NoProfile -ExecutionPolicy Bypass -File`; see its help for -DataRoot, -Theme, -Toolbar, -Clicks, -Keys, -Out)." Recommendation: add it.

## Hand checks
1. Start Noted from `app\build\windows\x64\runner\Release\noted.exe`. Open the gear menu → *AI connections*. "Claude Code" is listed (added by this run).
2. Restart Claude Code, so it starts the newly registered server. Ask it to call `list_my_boxes`. It answers with no boxes yet.
3. On a page, choose Insert → *AI box*. A box appears in the middle of the view, ready to type in. Type a line; it has no marker. Open *No connected AI* in the box's header and pick "Claude Code".
4. Right-click the page → *AI access* → *Box only*. Ask Claude Code to `write_box` into the box with `mode: "append"`.
   - The text appears at once with a thin bar beside it.
   - Escape, then Ctrl+Z, removes it in one step.
5. Ask Claude Code to `read_page` that page. Only the AI box is shown, and its text is between `<ai-written>` lines.
6. Revoke "Claude Code" in the dialog and ask for another write. It is refused as revoked, and the box keeps its text.
7. Quit Noted and ask for a write. It is refused because Noted isn't running, while `list_pages` still works.
8. Check CI on the final push: <https://github.com/NDouve/Noted/actions>.
