## Decisions the PM made
- **Box API:** no change and no version bump. `PageChange.landed`, `pageIssues` and the resolution helpers are host-only, as noted in the changelog. The interface between the issue UI and the AI merge (`PageAiMerge`, `AiMergeProposal`, including `by`) is in noted_canvas and is not part of the Box API.
- **Page format:** the `landed` field in a box's `noted` header. next.md requires issues to persist "across restarts and devices", which implies storing them in the page.
- **The page-AI merge design:**
  - A connected page AI means a covering, usable page or binder Reader code used in the last 15 minutes.
  - Requests live in memory and expire after 10 minutes.
  - A Reader is enough, since it only proposes.
  - The new link ops and tools are `merge_requests` and `propose_merge`, with the new error `no_request`.
- **Manual-edit merge view:** removed. next.md's choices (keep one, place both, ask the AI) replace it. This is recorded in 0120 and on 0051.
- **Silence** is per app run, shared across page switches. Issues that arrive while the page is open show the chip and the icon, not the dialog.
- **Merge strictness:** the "only added" rules for note and AI boxes, and that images and files merge only when identical.
- **Revoked codes** blank their hash, rather than bumping the store format, so old builds refuse only the revoked codes.
- **Approval names** use the label `Shown in Noted as: "…"`.
- **The warning glyph** is drawn as text, because the icon-font glyph went missing in the release build.
- **`search_ui_test`:** its teardown waits at most 20 s for the final save. The pages are scratch data.
- **The Codex review** was skipped (exit 2), as `pm.md` directs.
