## Done
- `.claude/agents/pm.md` (opus):
  - plans a run from `docs/runs/next.md` and splits it into tasks, each classified as normal, delegated (decide and log) or maintainer-only (park);
  - runs builders in parallel only on separate files, each in a worktree, and merges them;
  - routes every diff to `reviewer` and visible changes to `reviewer-ui`; nothing is committed with an open blocking finding;
  - finishes with analyze, all tests, the integration suite when the app changed, push and CI, the release rebuild, curation, and the report (committed together with the deletion of `next.md`);
  - keeps the GPU limits.
- `.claude/agents/builder.md` (sonnet): implements one task with tests that fail without it, runs analyze and the affected packages' tests, and doesn't widen scope or reformat unchanged code. It reports back instead of making a Box API change, dependency, format change, package or invariant-related change. It never commits.
- `.claude/agents/reviewer.md` (opus, no edit tools): checks the invariants, the ask-first and delegated-authority rules, correctness, security (injection, paths, URLs), licences and MPL headers, whether the tests would fail without the change, and personal information. Each finding is blocking or non-blocking, with `file:line` and a failure scenario.
- `.claude/agents/reviewer-ui.md` (sonnet, no edit tools): screenshots of the release build on scratch data (APPDATA redirected), in light and dark, captured from the window's own pixels, checked against `docs/design` and the request. Each finding is blocking or non-blocking.
- `CLAUDE.md`:
  - "Ask before" now points to the new section.
  - The new section "Build team and delegated authority" lets the PM decide additive Box API changes, Dart- or Flutter-team dependencies with allowed licences pinned to an exact version, and new packages under `packages/boxes/`.
  - Everything else (other "Ask before" items, scope, the invariants, encryption, the MCP boundary) goes to the maintainer through the report, without stopping the run.
- `docs/runs/README.md`: the loop (queue in `next.md`, start with "Run docs/runs/next.md as the PM", report as `docs/runs/YYYY-MM-DD-NN.md` with `next.md` deleted in the same commit) and the report format.
