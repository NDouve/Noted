# Menu

Context menus, the / menu, the table row/column handle menu and toolbar dropdowns.

- Container: `surface`, 1px `border`, `radius-lg`, `shadow-popover`, padding `space-1`, min width 220px.
- Item: height `row` (40px on touch), `radius-md`, padding `space-2` × 10px, `body` in `text`; hover or keyboard focus fills `surface-hover`. A shortcut sits right-aligned in `small` `text-muted`.
- Separator: 1px `border` with `space-1` margins.
- Disabled: `text-disabled`, no hover.
- Destructive (Delete page, Delete row): label in `error`, still confirmed before acting.
- Pick list (boxes under a point): the same container, anchored at the press and kept inside the canvas. A row is `<Type> · <first words>` in `body` (up to 60 characters of the snapshot text; an encrypted box shows its type only), with two icon buttons at the right, Bring to front and Send to back, in `text-muted` and `text` when enabled. The row under the pointer or keyboard highlight fills `surface-hover` and the canvas outlines its box (BoxFrame).
- Pick list row, third icon button: More (`more_horiz_rounded`, tooltip "Actions for this box"), after Bring to front and Send to back. It closes the list and opens that box's context menu at the press point.
- Canvas context menu (right click, Shift+F10, the Menu key, a touch hold on a box opens the pick list, whose More opens this menu): the same container, opened at the point and flipped left or up to stay 8px inside the window. Rows are `row` high (40px on touch) with an icon, the label and, for a registry command, its shortcut. A box menu: Bring to front, Bring forward, Send backward, Send to back, Pick overlapping box…, Delete box (`error`); a disallowed box shows the heading "Not allowed on this page" (`small`, `text-muted`) above the entries, with only Delete enabled. A canvas menu: New note here, Paste, then the module inserts. Keyboard focus is a solid 2px `accent` outline on the entry; Up, Down, Home, End and Tab move, Enter or Space runs, Escape closes.
- Radial context menu (opt-in, mouse only): six fixed slots 60° apart clockwise from the top, a pill each (icon and `label` text on `surface`, 1px `border`, `radius-lg`, at least `row` high). A box uses five slots (Bring to front, Delete box, Send to back, Pick overlapping box…, More) and the canvas five (New note here, Paste, Insert image, Insert file, More); the sixth stays empty, and a disabled entry keeps its slot, drawn disabled. More replaces the ring with the full menu. The ring radius is at least 88px, grown until no two pills are within 8px, and the ring is kept 8px inside the canvas area; a 6px `accent` dot marks the press point. It fades and scales in over 120ms, and not at all with reduced motion.
